This is some Python code I developed to allow a Lecturer, Internal Moderator and External Moderator to mark
assignment/exam scripts. It is a proof-of-concept I developed so it is a bit rough around the edges and is 
considered as a conceptual business process improvement for academics working at South African public 
universities. The initial version is 2.4.8 and that is the baseline to work from.
